# Husam Abdelfatah — Portfolio

Bilingual (EN/AR) static portfolio, hosted on GitHub Pages.

- Edit text in `src/content.mjs`, styles in `assets/css/style.css`
- Rebuild pages: `node build.mjs` (generates `index.html`, `ar/index.html`, `sitemap.xml`)
- Push to `main` → GitHub Pages publishes automatically
